# Spec Delta

## Purpose

用可复现的多故障场景库替代口头演示，通过回放已知根因的故障并自动比对诊断结论，量化平台在不同故障类型上的根因定位准确率与耗时，为优化 Prompt 与决策模型提供依据。

## ADDED Requirements

### Requirement: 故障场景定义与场景库

系统 SHALL 支持以结构化文件定义故障场景，场景 MUST 包含唯一标识、名称、故障类别、拓扑快照、带相对时间的告警序列、对应堆栈日志、期望根因类别、期望根因节点与期望影响范围；系统 MUST 至少内置 6 个覆盖不同故障类型的场景，并提供场景列表与详情查询。

#### Scenario: 列出内置场景

- **WHEN** 调用方请求场景列表
- **THEN** 系统返回不少于 6 个场景，每个场景包含标识、名称、故障类别与期望根因节点

#### Scenario: 拒绝非法场景

- **WHEN** 场景缺少期望根因或引用了拓扑中不存在的节点
- **THEN** 系统拒绝加载该场景并返回具体的校验错误位置与原因

### Requirement: 场景回放

系统 SHALL 按场景定义的时间压缩倍率依次注入告警与日志，生成与回放批次关联的故障事件；回放 MUST 可重复执行且每次回放产生独立的批次标识，不影响历史回放数据。

#### Scenario: 回放场景生成事件

- **WHEN** 调用方对某场景执行回放并指定时间压缩倍率
- **THEN** 系统生成该批次的告警、日志与故障事件，并返回批次标识与生成数量

#### Scenario: 回放可重复

- **WHEN** 同一场景被回放两次
- **THEN** 两次回放各自产生独立批次，历史批次与评估结果仍可查询

### Requirement: 诊断准确率评估

系统 SHALL 在评估模式下对回放产生的故障事件执行诊断，并将诊断结果与场景期望值比对，至少计算根因类别 Top-1 命中率、Top-3 命中率与根因节点定位准确率；比对 MUST 区分"结论正确"与"结论错误"并记录每例差异。

#### Scenario: 根因正确计入命中

- **WHEN** 诊断给出的根因类别与根因节点均与场景期望一致
- **THEN** 该用例被记录为 Top-1 命中，并在明细中标记为正确

#### Scenario: 根因错误计入未命中

- **WHEN** 诊断给出的根因节点与场景期望不一致
- **THEN** 该用例被记录为未命中，明细中同时保存期望值与实际值

### Requirement: 评估指标与结果查询

系统 SHALL 汇总一次评估的用例总数、Top-1 准确率、Top-3 准确率、节点定位准确率、平均诊断耗时与平均压缩比，并持久化评估批次结果；调用方 MUST 能按批次查询汇总指标与逐场景明细，并导出 JSON。

#### Scenario: 查询评估汇总

- **WHEN** 评估完成后调用方按批次查询结果
- **THEN** 系统返回用例总数、各项准确率、平均诊断耗时与平均压缩比

#### Scenario: 导出评估结果

- **WHEN** 调用方请求导出评估批次
- **THEN** 系统返回包含汇总指标与逐场景明细的 JSON 文件

### Requirement: 评估可复现

系统 SHALL 在评估模式下使用确定性的诊断配置（固定随机种子、回退优先或 Mock 模型），保证同一场景集在相同配置下重复评估得到相同的准确率结果。

#### Scenario: 重复评估结果一致

- **WHEN** 使用相同场景集、相同配置与相同随机种子连续执行两次评估
- **THEN** 两次评估的 Top-1 准确率、Top-3 准确率与节点定位准确率完全一致
