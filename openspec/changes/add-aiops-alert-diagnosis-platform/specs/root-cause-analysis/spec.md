# Spec Delta

## Purpose

把故障事件、核心告警与日志证据组织成一次可解释的诊断，先由确定性决策模型快速给出候选根因，再由大模型融合上下文输出根因结论与置信度，并在模型不可用时仍能给出可用的降级结论。

## ADDED Requirements

### Requirement: 决策模型快速故障检测

系统 SHALL 提供不依赖大模型的确定性决策模型，对故障事件给出按得分排序的候选故障类别与命中特征；同一事件的相同输入 MUST 得到相同输出，且单事件检测响应时间在演示规模下 MUST 小于 500 毫秒。

#### Scenario: 快速得到候选故障类别

- **WHEN** 调用方对已关联的故障事件请求快速检测
- **THEN** 系统返回按得分排序的故障类别列表、每类得分与命中特征，以及模型版本标识

#### Scenario: 确定性输出

- **WHEN** 对同一故障事件连续调用两次快速检测且输入未变化
- **THEN** 两次返回的候选类别、得分与排序完全一致

### Requirement: 诊断证据选择

系统 SHALL 为每次诊断选择证据集，包含根因候选节点上的核心告警与按错误特征筛选的日志片段；证据集 MUST 受条数与字节预算限制，并在结果中记录所引用的告警标识与日志标识。

#### Scenario: 证据受限且可追溯

- **WHEN** 一个故障事件关联 300 条告警与大量日志
- **THEN** 诊断只携带预算内的核心告警与日志片段，且诊断结果列出被引用的告警与日志标识

#### Scenario: 无日志时仍可诊断

- **WHEN** 故障事件只有告警而没有关联日志
- **THEN** 诊断仍执行完成，并在结果中说明日志证据缺失

### Requirement: 日志敏感信息脱敏

系统 SHALL 在把日志内容发送给外部大模型之前，对密码、访问令牌、密钥、身份证号、手机号等敏感字段执行脱敏；系统 MUST NOT 将未脱敏的原始日志发送给外部模型。

#### Scenario: 敏感字段被替换

- **WHEN** 日志片段中包含密码、令牌或手机号并进入诊断上下文
- **THEN** 发送给模型的内容中这些值已被替换为脱敏占位符，且诊断结果不包含原始敏感值

### Requirement: 大模型根因分析

系统 SHALL 通过 OpenAI 兼容接口调用大模型执行根因分析，要求模型返回结构化结果（根因类别、根因节点、影响范围、置信度、推理说明、证据引用、缺失证据）；系统 MUST 校验结构合法性，校验失败时重试，重试后仍失败则进入降级路径。

#### Scenario: 正常返回结构化根因

- **WHEN** 大模型在超时时间内返回符合结构约束的根因结果
- **THEN** 系统持久化根因类别、根因节点、置信度、推理说明与证据引用，并将诊断标记为成功

#### Scenario: 非法输出触发降级

- **WHEN** 大模型返回无法通过结构校验的内容且重试后仍不合法
- **THEN** 系统使用决策模型结果生成降级诊断，并标记该次诊断发生过输出校验失败

### Requirement: 大模型不可用时的降级

系统 SHALL 在大模型未配置、超时、限流或返回错误时自动降级为决策模型加模板化推理的结论；降级结果 MUST 明确标记来源为降级、给出不超过降级上限的置信度，并说明降级原因。

#### Scenario: 模型超时自动降级

- **WHEN** 大模型调用超过配置的超时时间
- **THEN** 系统返回降级诊断，标记来源为降级、记录超时原因，并且置信度不高于配置的降级上限

#### Scenario: 未配置模型仍可演示

- **WHEN** 系统未配置任何大模型凭据时发起诊断
- **THEN** 诊断仍成功返回降级结论，不返回服务器错误

### Requirement: 诊断任务幂等与可重跑

系统 SHALL 为故障事件生成带状态的诊断记录（排队、执行中、成功、降级、失败），同一事件在已有执行中的诊断时 MUST 复用该诊断而不是重复调用模型；已完成诊断允许重跑，重跑 MUST 生成新版本并保留历史版本。

#### Scenario: 并发诊断复用执行中任务

- **WHEN** 同一故障事件在诊断执行中被再次请求诊断
- **THEN** 系统返回正在执行的同一诊断标识，不产生额外的模型调用

#### Scenario: 重跑生成新版本

- **WHEN** 调用方对已完成诊断的故障事件请求重新诊断
- **THEN** 系统生成新版本诊断，历史版本仍可查询，查询详情时默认返回最新版本

### Requirement: 置信度与人工复核

系统 SHALL 在诊断置信度低于可配置阈值或关键证据缺失时，将诊断标记为需要人工复核，并在结果中列出缺失证据与建议补充的排查项。

#### Scenario: 低置信度标记复核

- **WHEN** 诊断置信度低于阈值且缺少根因节点的日志证据
- **THEN** 诊断结果标记为需要人工复核，并列出缺失的日志证据类别

### Requirement: 诊断结果可审计

系统 SHALL 在每次诊断记录中保存使用的模型标识、Prompt 版本、脱敏与证据预算配置版本、耗时与 token 用量；这些信息 MUST 可通过诊断详情接口查询。

#### Scenario: 查询诊断审计信息

- **WHEN** 调用方查询某次诊断详情
- **THEN** 响应包含模型标识、Prompt 版本、耗时与 token 用量等审计字段
